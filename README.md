# Project Eliza

A Java console program that simulates a simple Eliza-style conversation using user input, string processing, and randomized response templates.

## Features
- Asks for the user's name and accepts conversation input
- Extracts the first and last words from each sentence
- Removes common punctuation from words
- Changes its response based on sentence punctuation
- Randomly selects responses from question and statement arrays
- Uses two Java classes: `ProjectEliza` and `PromptBank`
- Supports EXIT and session restart behavior

## Concepts Used
- Java
- Classes and objects
- Arrays
- Methods
- Scanner input
- String methods
- while loops
- if / else statements
- Math.random()

## Files
- `ProjectEliza.java` — main conversation logic and helper methods
- `PromptBank.java` — response templates and random prompt selection
